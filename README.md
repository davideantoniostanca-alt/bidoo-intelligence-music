# Bidoo Intelligence — risorse musicali

Risorse musicali distribuite per la playlist automatica dell’app Bidoo Intelligence.

Solo risorse musicali e metadati. Nessun sorgente privato dell’app, dato account o credenziale.

Le opere appartengono agli artisti e mantengono le rispettive licenze. Bidoo Intelligence non è affiliata a FMA o agli artisti.
